# soccentric-lyra.github.io

Project site for Lyra, the SoCcentric open-source platform for the STM32F767ZI microcontroller: https://soccentric-lyra.github.io/

The page is generated, together with the nine Linux platform sites, by `site/gen_site.py` in the private project-managers repository, so all ten share one layout. Edit it there, not here.

The previous interactive site (slides, screen captures and recorded boot logs) is kept at the `classic-site` tag of this repository.
