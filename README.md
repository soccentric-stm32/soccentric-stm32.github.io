# soccentric-stm32.github.io

Project site for the SoCcentric STM32 work on the NUCLEO-F767ZI: hardware
validation firmware, A/B bootloader, FreeRTOS application and the
cross-platform validation GUI.

Published with GitHub Pages from the `main` branch root at
<https://soccentric-stm32.github.io>. Plain HTML and CSS, no build step
(`.nojekyll` turns Jekyll off). To preview locally:

```bash
python3 -m http.server 8000
```
